Extract spiDE’s test results

Description

Extract spiDE’s test results

Usage

results(object, ...)

## S4 method for signature 'SpiDEResults'
results(object, test = NULL, fdr = NULL, ...)

Arguments

object a SpiDEResults.
… unused.
test NULL (the condition-specific test if one was run, else the pooled test), “condition”, “pooled” or “both”.
fdr NULL (every tested triplet) or a level: keep rows with q <= fdr.

Value

a data.frame, one row per (gene, index, niche, test), ordered by p-value: estimate (the pooled slope, or the difference in slope between conditions, on the log scale per unit log1p niche density), se, t, df, p, q (BH within the test’s family), in_family and, for the slopes engine, p.heterogeneity (the label-free test that the triplet’s slopes vary between patients, the filter of procedure = “heterogeneity”). Condition-specific rows outside the family have q = NA.

Examples

library("spiDE")

data(toySpiDE)
res <- spiDE(toySpiDE, condition = "condition", sigma = 30, index = "A",
             procedure = "all")
results(res, test = "pooled")
