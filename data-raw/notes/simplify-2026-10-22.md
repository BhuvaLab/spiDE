### 2. `testNicheAbundance()` ignores merged niches - e9b1fef - **output changes**
Uses `.isSelfNiche()` with `metadata(spe)$spiDE_niche_groups[[paste0(name, sigma)]]` (as `fitSpiDE` does) in place of
`setdiff(niches, k)`, and maps the sanitised names back so `index` and `niche` read as in the data.
Output changes only for (a) inputs whose niche reducedDim was merged with `mergeNiches()` (the index type's own merged niche
is no longer tested) and (b) labels with a space or hyphen (`"T cell"` instead of `"T.cell"`). Unmerged inputs with syntactic
names are bit-identical (compared on the 12-sample composition fixture, genes and gene sets).
Reproduce on `data(toySpiDE)`:
```r
data(toySpiDE); spe <- buildNiches(toySpiDE, sigma = 30, verbose = FALSE)
m  <- mergeNiches(spe, list(AC = c("A", "C")), sigma = 30)
na <- testNicheAbundance(m, condition = "condition", sigma = 30, index = "A", verbose = FALSE)
unique(na$niche)                     # before: "AC" "B"          after: "B"
s2 <- toySpiDE; s2$cell_type <- c(A = "T cell", B = "B-cell", C = "C")[s2$cell_type]
s2 <- buildNiches(s2, sigma = 30, verbose = FALSE)
unique(testNicheAbundance(s2, condition = "condition", sigma = 30, verbose = FALSE)$index)
                                     # before: "B.cell" "C" "T.cell"   after: "B-cell" "C" "T cell"
```
Files: `R/niche-abundance.R` (`testNicheAbundance`), tests in `tests/testthat/test-niche-abundance.R` (two new `test_that`s;
both fail on fe71912's code, checked by running the file against that tree: 5 failures on the merged-niche and label tests).
Python port: same rule as `fitSpiDE` (self-niche = index is the niche, or a member of the merged group, group name counts as
a member); output `index`/`niche` columns carry the original labels; internal matching may stay on sanitised names.

Python port: split by sample index, compute per sample from coordinates and labels only, write into a preallocated
(cells x all types, zero-filled) array by index.
